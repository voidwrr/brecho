# 🛍️ Sistema de Gestão de Brechó

Aplicação web interativa para gestão de inventário e vendas de brechó, desenvolvida em **Python** com **Streamlit** e banco de dados **SQLite**.

---

## 📌 Funcionalidades

- **Gestão de Inventário**: Registo, edição e consulta de artigos disponíveis no brechó.
- **Registo de Vendas**: Controlo e histórico de transações efetuadas.
- **Base de Dados**: Estrutura relacional otimizada (`schema.sql`).
- **Execução Facilitada**: Script executável em Windows (`Brecho.bat`) para iniciar a aplicação com um clique.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **Streamlit** (Interface gráfica)
- **SQLite** (Base de dados relacional)
